HAN рассматривается как ключевая концептуальная модель для учёта разной "важности" узлов и связей (CEX ≠ DEX ≠ mixer) и как теоретическая основа для SemiGNN.

### Зачем нужен HAN в AML

В блокчейн‑графах:

- узлы имеют **разную семантику и репутационное влияние**;
- связи между узлами тоже неоднородны;
- важность соседей не может считаться одинаковой.

Обычные GNN (GCN, GraphSAGE):

- усредняют вклад соседей;
- не учитывают типы узлов и рёбер;
- плохо работают с гетерогенными графами.

**HAN решает именно эту проблему.**

### Meta‑paths — основа HAN

**Meta‑path** — это типовой путь в гетерогенном графе.

Примеры для AML:

- Address → CEX → Address
- Address → Mixer → Address
- Address → Token → Address

Каждый meta‑path отражает **отдельный поведенческий паттерн**.

### Двухуровневый Attention в HAN

HAN использует **Dual Attention**:

1. **Node‑level attention**

Определяет важность соседних узлов **в рамках одного meta‑path**.

Интуитивно:

- сосед через mixer весит больше, чем обычный адрес;
- связь с CEX может быть более значимой.

Формирует embedding для каждого meta‑path.

2. **Semantic‑level attention**

Определяет важность **разных meta‑paths** между собой.

Пример:

- path через mixer > path через обычный transfer;
- token‑based path важнее нативного transfer.

Итоговое представление узла — взвешенная комбинация meta‑path embedding.

### Почему HAN подходит для real‑time AML

Преимущества:

- явная интерпретируемость (что именно повлияло на оценку);
- учёт типа узлов и связей;
- гибкость при добавлении новых типов узлов.

Ограничения:

- необходимость заранее задать meta‑paths;
- рост вычислительной сложности при большом числе путей;
- требует аккуратного проектирования признаков.

Для real‑time сценариев:

- возможна оценка на локальном подграфе;
- attention можно ограничивать top‑K соседями.

### Связь HAN и SemiGNN

SemiGNN использует идеи HAN:

- multi‑view представление;
- attention между представлениями;
- работу с частично размеченными данными.

Можно рассматривать SemiGNN как развитие HAN под финансовые и AML‑задачи.

### Роль HAN в дипломной работе

HAN:

- объясняет, **почему важность узлов различна**;
- даёт теоретическую базу для Dual Attention;
- оправдывает выбор SemiGNN как основной модели.
