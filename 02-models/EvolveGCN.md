**EvolveGCN** — это расширение классической Graph Convolutional Network (GCN), предназначенное для анализа **динамических графов**, структура и признаки которых изменяются во времени. Ключевая особенность модели заключается в эволюции параметров GCN с использованием рекуррентных нейронных сетей.

**Проблема статических GNN**

Классические графовые нейронные сети предполагают, что граф является статическим. Однако в задачах AML транзакционный граф:

- непрерывно пополняется новыми узлами и связями;
- отражает временную динамику поведения пользователей;
- содержит паттерны мошенничества, проявляющиеся во времени.

Статические модели не способны корректно учитывать эти изменения.

**Основная идея EvolveGCN**

В EvolveGCN параметры графовой сверточной сети не являются фиксированными. Вместо этого они обновляются на каждом временном шаге с использованием рекуррентного механизма (GRU или LSTM).

Использование динамических графов мотивировано результатами исследования [[Anti-Money Laundering in Bitcoin using GCN (Weber et al., 2019)]], где транзакции распределены по временным шагам.

Таким образом:

1. GCN извлекает структурные признаки графа;
2. RNN отвечает за адаптацию параметров модели во времени;
3. Модель учитывает историю развития графа.

**Архитектурный принцип**

1. На каждом временном шаге формируется временной срез графа.

2. К текущему срезу применяется GCN.

3. Параметры GCN обновляются рекуррентной сетью.

4. Полученные представления узлов используются для классификации или выявления аномалий.

**Значимость для AML-анализа**

Использование EvolveGCN позволяет:

- учитывать эволюцию транзакционной сети;
- выявлять временные аномалии и подозрительные паттерны;
- повышать устойчивость модели к изменению поведения адресов.

Это делает модель особенно перспективной для анализа блокчейн-транзакций.

**Transfer Learning в AML-задачах**

В условиях ограниченного количества размеченных данных EvolveGCN может применяться совместно с transfer learning. Это позволяет переносить знания между различными транзакционными графами и ускорять адаптацию модели к новым данным.

**Связь с дипломом**

Подход EvolveGCN расширяет возможности анализа по сравнению со статическими GNN и может быть использован для обоснования архитектурных решений в рамках дипломной работы.
