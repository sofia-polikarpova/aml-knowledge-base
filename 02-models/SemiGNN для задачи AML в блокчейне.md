В рамках дипломной работы рассматривается задача **AML (Anti-Money Laundering)** анализа блокчейн‑транзакций. Блокчейн‑данные естественным образом представляются в виде **графа**, где:

- узлы — адреса / сущности (user, CEX, DEX, mixer и т.д.),
- рёбра — транзакции между ними.

Граф характеризуется:

- гетерогенностью (разные типы узлов и связей),
- высокой разреженностью,
- сильной временной динамикой,
- наличием репутационных различий между узлами.

В качестве базовой модели выбрана **SemiGNN**, реализованная в составе фреймворка **DGFraud‑TF2**.

### Краткое описание SemiGNN

**SemiGNN (Semi‑Supervised Graph Neural Network)** — графовая нейросеть, предназначенная для задач обнаружения мошенничества, использующая:

- полу‑обучение (semi‑supervised learning),
- механизм внимания (attention),
- multi‑view представление графа.

**Основные идеи модели**

1. **Semi‑supervised обучение**

- модель обучается на небольшом количестве размеченных узлов;
- информация распространяется по графу через соседей.

2. **Attention‑механизм**

- вклад соседних узлов взвешивается по важности;
- модель учится фокусироваться на наиболее информативных связях.

3. **Multi‑view графы**

- один и тот же набор узлов может быть связан разными типами рёбер;
- каждый view агрегируется отдельно.

### Почему SemiGNN подходит для блокчейн‑AML

Преимущества:

- естественная работа с графовой структурой;
- устойчивость к сильному дисбалансу классов;
- возможность учитывать разные типы связей;
- интерпретируемость через attention‑веса.

Ограничения оригинальной реализации:

- отсутствует явная работа с edge‑features;
- не учитывается временная динамика;
- репутация узлов не выделена как отдельный фактор.

Именно эти ограничения и являются точками для улучшения модели.

### Улучшения SemiGNN для AML‑задачи

**1. Расширение признаков узлов (Node Features)**

В оригинальной реализации SemiGNN предполагается наличие абстрактных признаков узлов. Для блокчейн‑AML предлагается расширить их следующим образом:

**Финансовые признаки:**

- текущий баланс адреса;
- суммарный входящий объём;
- суммарный исходящий объём;
- средняя сумма транзакции.

**Поведенческие признаки:**

- количество транзакций;
- частота операций;
- средний интервал между транзакциями.

**Временные признаки:**

- возраст адреса;
- время с последней активности.

**Семантические признаки:**

- тип сущности (User / CEX / DEX / Mixer);
- взаимодействие с сервисами повышенного риска.

**Репутационные признаки:**

- бинарный или числовой репутационный score;
- принадлежность к известным сервисам.

Эти признаки формируют основу для вычисления "важности" узлов в attention‑механизме.

**2. Учёт различий типов узлов (CEX ≠ DEX ≠ Mixer)**

В AML‑задаче разные типы узлов обладают разной семантикой:

- CEX — легитимные централизованные сервисы;
- DEX — децентрализованные протоколы;
- Mixers — сервисы повышенного риска.

Предлагаемые решения:

- one‑hot / embedding кодирование типа узла;
- использование типа узла как отдельного признака в attention;
- задание априорных весов для разных типов сущностей.

**3. Расширение признаков рёбер (Edge Features)**

В стандартной SemiGNN рёбра используются только как структура графа. Для блокчейн‑задачи предлагается учитывать:

- сумму транзакции;
- направление перевода;
- частоту взаимодействий;
- временные интервалы между транзакциями;
- тип операции (transfer / contract call).

Возможные варианты интеграции:

- агрегация edge‑features в node‑features;
- модификация attention‑механизма для учёта признаков рёбер.

**4. Multi‑view представление блокчейн‑графа**

Предлагается использовать разные views графа:

view 1: обычные переводы между адресами;

view 2: взаимодействия с CEX;

view 3: взаимодействия с mixers;

view 4: смарт‑контрактные вызовы.

Каждый view агрегируется отдельно, после чего представления объединяются attention‑механизмом.

**5. Учёт временной динамики (опционально)**

Для дальнейшего развития модели возможно:

- обучение на временных срезах графа;
- использование sliding window;
- интеграция идей EvolveGCN.

**6. Применимость в режиме близком к реальному времени**

Для практического AML‑использования важно:

- быстрое вычисление embedding;
- inductive‑подход (GraphSAGE‑подобный);
- ограничение размера локального подграфа.

SemiGNN может быть адаптирована для offline‑обучения и online‑inference.

### Научная новизна и вклад

В рамках дипломной работы:

- адаптация SemiGNN под специфику блокчейн‑AML;
- расширение набора node‑ и edge‑features;
- учёт репутационного веса узлов;
- анализ attention‑весов для интерпретации результатов.

Данные улучшения не меняют базовую архитектуру модели, но существенно повышают её применимость для реальных AML‑сценариев.
