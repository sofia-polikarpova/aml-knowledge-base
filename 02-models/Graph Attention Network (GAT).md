**Graph Attention Network (GAT)** — это разновидность графовых нейронных сетей (GNN), в которой при агрегации информации от соседних узлов используется механизм внимания (attention). Attention позволяет модели автоматически определять относительную важность соседних узлов при формировании представления текущего узла.

**Мотивация использования Attention в графах**

В реальных графах, в частности в транзакционных графах блокчейна, узлы могут иметь большое количество соседей, при этом вклад различных связей в поведение узла существенно различается. Классические графовые модели (GCN) предполагают равный вклад всех соседей, что может приводить к потере значимой информации.

В работе [[Anti-Money Laundering in Bitcoin using GCN (Weber et al., 2019)]] показано, что учет графовой структуры улучшает выявление нелегитимных транзакций, что мотивирует использование attention-механизмов.

Механизм attention позволяет модели:

- фокусироваться на наиболее информативных связях;
- снижать влияние шумовых транзакций;
- учитывать неоднородность структуры графа.

**Принцип работы Attention в GAT**

1. Исходные признаки узлов проецируются в новое латентное пространство.

2. Для каждой пары связанных узлов вычисляется attention-коэффициент, отражающий важность соседнего узла.

3. Attention-коэффициенты нормализуются с помощью функции softmax.

4. Информация от соседей агрегируется как взвешенная сумма.

Для повышения устойчивости и выразительности модели используется **multi-head attention**, при котором несколько attention-механизмов обучаются параллельно.

**Значимость GAT для AML-задач**

Использование GAT особенно эффективно в задачах AML-анализа, поскольку:

- транзакционные графы обладают высокой степенью шума;
- мошеннические паттерны часто скрыты в небольших подграфах;
- не все транзакции одинаково информативны для выявления фрода.

Attention позволяет модели выделять подозрительные связи и учитывать сложные паттерны взаимодействий между адресами.

**Связь с дипломом**

Механизм attention концептуально используется в ряде моделей для fraud detection на графах и лежит в основе архитектур, применяемых в фреймворке [[DGFraud-TF2]].
