# Models

## Обзор исследуемых моделей

### Основные модели проекта
- [[DGFraud-T2]] - Графовая нейронная сеть (основной фокус)
- [[Money Laundering Detection]] - Табличный подход (второстепенный)

### Критерии выбора моделей
1. **Эффективность** для AML-задач
2. **Возможность адаптации** к блокчейн-данным
3. **Наличие документации** и примеров реализации
4. **Требования к вычислительным ресурсам**

## Сравнительная таблица

| Параметр                     | DGFraud-T2              | Money Laundering Detection |
| ---------------------------- | ----------------------- | -------------------------- |
| **Тип модели**               | Графовая нейронная сеть | Классическая ML            |
| **Подход к данным**          | Анализ связей           | Анализ признаков           |
| **Требования к данным**      | Сырые транзакции        | Готовые признаки           |
| **Сложность реализации**     | Высокая                 | Средняя                    |
| **Интерпретируемость**       | Средняя                 | Высокая                    |
| **Обнаружение сложных схем** | Эффективно              | Ограничено                 |
