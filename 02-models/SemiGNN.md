**Semi-supervised Graph Attentive Network for Fraud Detection** 

**Источник**

**Статья:** A Semi-supervised Graph Attentive Network for Financial Fraud Detection **arXiv:** 2003.01171 **Год:** 2020

**Краткое описание**

**SemiGNN** — это полуобучаемая графовая нейронная сеть, предназначенная для задач финансового мошенничества в условиях:

- малого количества размеченных данных;
- наличия неразмеченных узлов;
- сложной графовой структуры с несколькими типами связей.

Модель использует **иерархический механизм attention**, что делает её более интерпретируемой по сравнению с классическими GNN.

**Постановка задачи**

В реальных AML-сценариях:

- большинство транзакций и пользователей не имеют меток;
- данные представлены в виде графов;
- существует несколько типов связей между сущностями.

Классические модели плохо масштабируются на такие условия, что мотивирует использование semi-supervised GNN.

**Мультивью представление графа**

SemiGNN использует **несколько графов (views)**, каждый из которых отражает отдельный тип отношений:

- транзакционные связи;
- социальные связи;
- атрибутные сходства.

Каждый view обрабатывается отдельно, после чего информация агрегируется.

**Иерархический механизм Attention**

**1. Node-level Attention**

Определяет вклад каждого соседнего узла при обновлении представления текущего узла. Аналогично Graph Attention Network (GAT), но применяется отдельно для каждого view.

**2. View-level Attention**

Определяет относительную важность различных видов графов (views) при формировании итогового представления узла.

Таким образом, модель автоматически обучается:

- какие соседи важны;
- какие типы связей важнее для выявления мошенничества.

**Процесс обучения (Semi-supervised)**

Обучение происходит с использованием:

- размеченных узлов (fraud / non-fraud);
- неразмеченных узлов, информация от которых распространяется через граф.

Это позволяет повысить качество модели в условиях дефицита меток, характерного для AML-задач.

**Интерпретируемость**

Attention-коэффициенты могут использоваться для:

- анализа наиболее значимых связей;
- объяснения решений модели;
- визуализации подозрительных паттернов.

Это является важным преимуществом модели в практических финансовых расследованиях.

**Значимость для диплома:

SemiGNN:

- расширяет GAT за счёт multi-view и semi-supervised обучения;
- хорошо соответствует условиям реальных AML-данных;
- может быть рассмотрена как основная архитектура дипломной работы;
- концептуально совместима с идеями, реализованными в DGFraud-TF2.
