**Общее описание**

**Elliptic Data Set** — это публичный набор данных транзакций Bitcoin, предназначенный для исследований в области Anti-Money Laundering (AML). Датасет был представлен в работе Weber et al. (2019) и является одним из немногих размеченных реальных наборов данных для анализа нелегальной активности в блокчейне.

**Структура графа**

**Узлы:** отдельные транзакции Bitcoin
**Рёбра:** потоки средств между транзакциями (transaction flow)
**Тип графа:** ориентированный граф
**Размер:**
~203 000 узлов
~234 000 рёбер

Граф отражает реальные финансовые потоки между транзакциями и используется для построения моделей финансовой форензики.

**Временная динамика**

Транзакции распределены по **49 временным шагам (time steps)**.

Каждый временной шаг соответствует определённому периоду активности сети, что позволяет рассматривать граф как **динамический**.

Это делает датасет особенно подходящим для:

- динамических GNN;
- временного анализа мошеннических паттернов;
- моделей, учитывающих эволюцию поведения адресов.

**Признаки (166 features)**

Каждая транзакция описывается вектором из **166 числовых признаков**, которые делятся на две группы:

**1. Локальные признаки (94)**

Характеризуют саму транзакцию без учёта графовой структуры:

- количество входов и выходов;
- объёмы входящих и исходящих средств;
- комиссии;
- статистики входов/выходов (средние значения и др.).

**2. Агрегированные графовые признаки (72)**

Формируются на основе соседних транзакций:

- статистические агрегаты (min, max, mean, std);
- корреляции между признаками соседей;
- характеристики локального окружения узла.

Точные семантические названия признаков не опубликованы по юридическим причинам, однако их структура полностью известна.

**Разметка классов**

- **licit** — легальные транзакции
- **illicit** — нелегальные транзакции
- часть узлов остаётся неразмеченной

Набор данных является **сильно несбалансированным**, что отражает реальные AML-сценарии.

**Значимость для дипломного проекта**

Elliptic Data Set используется как:

1. Академический benchmark для AML-моделей;
2. Пример реального транзакционного графа;
3. Основа для сравнения классических ML и GNN-подходов.
