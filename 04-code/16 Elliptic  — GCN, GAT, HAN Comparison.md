### 1. Постановка эксперимента  
  
Задача: выявление мошеннических транзакций (fraud detection) в графе блокчейн-транзакций.  
  
Данные полного эксперимента:  
  
- Узлы: 203 769  
- Рёбра: 234 355  
- Признаки: 165  
- Размеченные узлы: 46 564  
- Классы: 0 — легитимная транзакция, 1 — мошенничество  
  
Основные метрики:  
  
- PR-AUC  
- F1-score (fraud)  
- Precision / Recall  
  
### 2. Результаты моделей на полном графе  
  
#### GCN  
  
- PR-AUC: 0.71  
- F1 (fraud): 0.56  
  
Характеристика:  
  
- устойчивый baseline;  
- хороший общий баланс;  
- умеренный recall.  
  
#### GAT  
  
- PR-AUC: ~0.73  
- F1 (fraud): ~0.58  
  
Характеристика:  
  
- лучший результат по PR-AUC среди baseline-моделей;  
- лучше ранжирует положительный класс;  
- чуть выше precision по сравнению с GCN.  
  
#### HAN  
  
- PR-AUC: 0.681  
- F1 (fraud): 0.601  
- Precision (fraud): 0.52  
- Recall (fraud): 0.70  
  
Характеристика:  
  
- лучший F1-score среди моделей полного графа;  
- самый высокий recall;  
- более агрессивно выявляет мошеннические транзакции.  
  
### 3. Результаты SemiGNN на подграфе 3000 узлов  
  
Важно: результат SemiGNN получен на подграфе из 3000 узлов с отдельным протоколом обучения, поэтому сравнение с полнографовыми моделями носит ориентировочный характер.  
  
- Accuracy: 0.7883  
- PR / Precision (fraud): 0.2830  
- Recall (fraud): 0.7759  
- F1-score (fraud): 0.4147  
- ROC-AUC: 0.8428  
  
Характеристика:  
  
- высокая чувствительность к fraud-классу;  
- сильное ранжирование объектов;  
- заметное число ложноположительных срабатываний;  
- лучше подходит как модель раннего обнаружения подозрительных адресов.  
  
### 4. Сводная таблица  
  
| Модель  | Протокол     | PR-AUC / ROC-AUC | F1 (fraud) | Особенность                                    |
| ------- | ------------ | ---------------: | ---------: | ---------------------------------------------- |

### 5. Аналитический вывод  
  
1. Среди моделей полного графа лучшим F1-score для fraud показывает HAN.  
2. GAT лидирует по качеству ранжирования положительного класса.  
3. SemiGNN на подграфе из 3000 узлов показывает высокий ROC-AUC и высокий recall, но F1 уступает full-graph HAN из-за компромисса между precision и recall.  
4. Для AML-задачи наиболее важным остаётся не только высокий F1, но и способность не пропускать мошеннические адреса.  
  
### 6. Научный вывод для диплома  
  
Результаты показывают, что графовые модели действительно полезны для AML-анализа блокчейн-графов. При этом эффективность модели зависит от протокола эксперимента, размера графа и способа балансировки классов.  
  
SemiGNN перспективна как гибкая архитектура для выявления подозрительной активности, особенно в сценариях, где важна высокая полнота обнаружения fraud-класса.
