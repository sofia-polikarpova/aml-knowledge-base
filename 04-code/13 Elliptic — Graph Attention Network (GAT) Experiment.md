### Контекст

После реализации GCN следующим этапом стало усложнение архитектуры за счёт введения механизма внимания.

Цель — проверить, улучшает ли attention качество выявления мошеннических транзакций на Elliptic Dataset при сильном дисбалансе классов.

- GCN агрегирует соседей с фиксированной нормализацией.  
- GAT позволяет модели обучаемо определять значимость каждого соседа.
### Теоретическое основание

В GAT агрегация выполняется через механизм внимания:
- для каждой пары соседних узлов вычисляется коэффициент важности;
- применяется softmax-нормализация;
- используется multi-head attention для стабилизации обучения.

Это увеличивает выразительную способность модели по сравнению с GCN.

Ожидание:  модель сможет лучше выделять значимые транзакционные связи и повысить качество по minority-классу.
### Архитектура модели

Использованная конфигурация:
- 2 слоя GATConv  
- multi-head attention  
- скрытое пространство размерности 64  
- dropout  
- линейный выходной слой  
- CrossEntropyLoss  
- оптимизатор Adam  

Обучение проводилось на том же train/test split, что и для GCN.
### Динамика обучения

Loss по эпохам:

```
Epoch 0  → 2.6675
Epoch 10 → 1.5452
Epoch 20 → 0.6813
Epoch 30 → 0.6244
Epoch 40 → 0.6263
```
  
Наблюдения:
- высокое начальное значение функции потерь;
- быстрое снижение на первых эпохах;
- после 30-й эпохи снижение стабилизируется;
- наблюдается небольшая нестабильность на финальных этапах обучения.

По сравнению с GCN обучение менее плавное.
### Результаты на test-выборке

Accuracy: **0.7847**

**Класс 0 (licit):**
- Precision: 0.9993  
- Recall: 0.7815  
- F1-score: 0.8771  

***Класс 1 (illicit):**
- Precision: 0.0721  
- Recall: 0.9688  
- F1-score: 0.1342  

PR-AUC: **0.2950**
### Анализ результатов
1. Модель демонстрирует очень высокий recall по классу illicit (≈0.97).  
   Практически все мошеннические транзакции обнаруживаются.

2. Однако precision крайне низкий (≈0.07).  
   Значительное количество ложноположительных срабатываний.

3. Accuracy ниже, чем у GCN.

4. PR-AUC составляет 0.2950, что уступает результату GCN.

Таким образом, attention усиливает чувствительность к minority-классу, но снижает способность модели корректно фильтровать ложные срабатывания.
### Интерпретация

В условиях Elliptic Dataset:
- граф является однородным;
- связи между транзакциями не имеют разных типов;
- структура графа разреженная.

В такой постановке механизм attention:
- не получает дополнительной семантической информации;
- может усиливать шумовые связи;
- не обеспечивает прироста ранжирующей способности.

Более сложная архитектура не привела к улучшению PR-AUC.
### Вывод
1. Реализована и обучена модель Graph Attention Network.  
2. Проведена оценка на test-выборке с использованием PR-AUC.  
3. Получено значение PR-AUC = 0.2950.  
4. Модель демонстрирует высокий recall, но критически низкий precision по minority-классу.  
5. Прироста качества по сравнению с GCN не зафиксировано.
