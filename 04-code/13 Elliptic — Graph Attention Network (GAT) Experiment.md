### Контекст

После реализации GCN следующим этапом стало усложнение архитектуры за счёт введения механизма внимания.

Цель — проверить, улучшает ли attention качество выявления мошеннических транзакций на Elliptic Dataset при сильном дисбалансе классов.

- GCN агрегирует соседей с фиксированной нормализацией.  
- GAT позволяет модели обучаемо определять значимость каждого соседа.
### Теоретическое основание

В GAT агрегация выполняется через механизм внимания:
- для каждой пары соседних узлов вычисляется коэффициент важности;
- применяется softmax-нормализация;
- используется multi-head attention для стабилизации обучения.

Это увеличивает выразительную способность модели по сравнению с GCN.

Ожидание:  модель сможет лучше выделять значимые транзакционные связи и повысить качество по minority-классу.

### Цель эксперимента  
  
На данном этапе была реализована GAT-модель для выявления мошеннических транзакций в графе Bitcoin (Elliptic dataset).  
  
Задачи этапа:  
- построить граф транзакций  
- подготовить признаки и метки  
- обучить attention-based GNN  
- компенсировать классовый дисбаланс  
- получить baseline-результаты  
- оценить качество выявления illicit-транзакций  
  
В работе использовался подграф из 3000 узлов. Это было сделано для того, чтобы уместить эксперимент в доступные вычислительные ресурсы и стабильно запускать обучение и сравнение моделей. Использование подграфа ускоряет эксперименты, но влияет на итоговое качество: GAT обучается на более ограниченном локальном контексте, поэтому качество сильнее зависит от структуры выбранного фрагмента графа, чем при работе на полном графе.

Поэтому GAT в таком режиме особенно чувствителен к тому, какие узлы оказались в подграфе и насколько хорошо в нём сохранились локальные связи между illicit и licit-объектами.

### Разметка  
  
После фильтрации:  
- Number of labeled nodes: 600  
- Licit: 542  
- Illicit: 58  
  
Дисбаланс  
- llicit ≈ 9.7%  
- Licit ≈ 90.3%  
  
Как и в случае с GCN, accuracy здесь не может быть основной метрикой. Для такой задачи важнее смотреть на precision, recall, F1 и PR-AUC, поскольку модель должна не просто давать много положительных предсказаний, а делать это достаточно точно.

### Предобработка

1. Замена inf → nan
2. Замена nan → 0
3. Нормализация StandardScaler
4. Добавление class weights

```
weight_illicit = 1 / num_illicit
weight_licit   = 1 / num_licit
```

Использование class weights помогает сместить обучение в сторону minority-класса, но для GAT особенно важен ещё и threshold. Attention-модель может выдавать более “мягкие” вероятности, поэтому итоговое качество сильно зависит от того, на каком пороге переводятся вероятности в классы. В этом эксперименте threshold оказался равен 0.88, что позволило существенно сократить число ложноположительных срабатываний по сравнению с более ранними вариантами.

### Архитектура модели

Архитектура модели  
```
GAT(  
(conv1): GATConv(165, 64)  
(conv2): GATConv(64, 2)  
)  
```

**Параметры:**
- lr = 0.001  
- weight_decay = 5e-4  
- 80 эпох

Обучение проводилось на том же train/test split, что и для GCN.

### Интерпретация  
  
**Recall (Illicit) = 0.7414**
  
Модель находит около 74% мошеннических транзакций. Это неплохой результат, но он ниже, чем у сильнейших конфигураций GCN в текущем протоколе.  
  
**Precision (Illicit) = 0.5811** 
  
Среди найденных мошеннических транзакций примерно 58% действительно являются мошенническими. Ложноположительных срабатываний заметно больше, чем у GCN, но меньше, чем в ранних неотстроенных версиях. Это означает, что GAT стала более аккуратной, но всё ещё даёт довольно много FP.  
  
**Accuracy = 0.9233**
  
Метрика высокая, однако сама по себе не отражает реальное качество в условиях дисбаланса. Для AML-задачи более информативны precision, recall, F1 и PR-AUC.  
  
Итоговый threshold = 0.88 показывает, что для отнесения узла к illicit требуется довольно высокая уверенность модели. Это снижает число ложных тревог, но GAT всё равно остаётся менее точной по precision, чем GCN в новой постановке.

### Вывод  
  
GAT демонстрирует:  
- способность использовать структурный и соседский контекст графа  
- приемлемое выявление illicit-паттернов  
- устойчивое обучение на подграфе  
  
Однако:  
- качество остаётся ниже, чем у GCN  
- число false positives всё ещё заметное  
- attention-механизм в текущем подграфовом режиме не дал существенного выигрыша

### Научное значение  
  
Этот этап:  
- подтверждает применимость attention-based GNN для AML  
- служит сопоставимым baseline  
- показывает, что не каждая более сложная архитектура автоматически даёт лучший результат

### Итог этапа  
  
GAT:  
- успешно обучена  
- показывает умеренно хороший recall при средним precision  
- формирует рабочий baseline  
- готова к сравнению с GCN, HAN и SemiGNN  
  
Главный вывод по новому эксперименту: на данном подграфе GAT работает стабильнее, чем в ранних версиях, но всё ещё уступает GCN по общей сбалансированности качества и точности выявления illicit-узлов.
