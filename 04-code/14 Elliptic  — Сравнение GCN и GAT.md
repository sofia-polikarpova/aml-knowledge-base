### Контекст

На данном этапе проводится сравнительный анализ двух графовых архитектур:
- GCN  
- GAT  

Цель — определить, обеспечивает ли механизм attention улучшение качества в задаче выявления мошеннических транзакций при сильной несбалансированности классов.
### Исходная постановка эксперимента

На начальном этапе:
- применялось стандартное случайное разбиение выборки;
- оценка качества основывалась преимущественно на accuracy;
- дисбаланс классов (~1:57) не учитывался при интерпретации результатов;
- ранжирующая способность модели не анализировалась.

Наблюдались:
- высокая accuracy;
- высокий recall по классу fraud;
- крайне низкий precision по классу fraud;
- значительное количество ложноположительных срабатываний.
### Ограничения исходного подхода

1. Accuracy не является репрезентативной метрикой при сильном дисбалансе.  
2. Высокий recall может достигаться за счёт роста false positives.  
3. Отсутствовал анализ PR-кривой и PR-AUC.  
4. Сравнение архитектур не отражало их способности к корректному ранжированию мошеннических транзакций.

Таким образом, исходная постановка не обеспечивала строгой методологической оценки.
### Внесённые изменения

**1. Корректный train/test split**
- Разбиение 80 / 20  
- Фиксированный random_state  
- Контроль распределения классов  

Обеспечена корректная оценка обобщающей способности моделей.

**2. Сравнение в идентичных условиях**
- одинаковое число эпох;  
- одинаковый pipeline обучения;  
- одинаковая функция потерь.  

Исключено влияние побочных факторов.

**3. Введение PR-анализа**

Дополнительно рассчитаны:
- precision;  
- recall;  
- F1-score;  
- PR-кривые;  
- PR-AUC.  

В условиях дисбаланса основной метрикой выбрана PR-AUC.
### Результаты

**GCN:**
- Accuracy: 0.8816  
- Precision (fraud): 0.1148  
- Recall (fraud): 0.8750  
- PR-AUC: **0.3709**

**GAT:**
- Accuracy: 0.7847  
- Precision (fraud): 0.0721  
- Recall (fraud): 0.9688  
- PR-AUC: **0.2950**
### Анализ
- GAT демонстрирует более высокий recall по minority-классу.  
- Однако это достигается ценой значительного снижения precision.  
- GCN обеспечивает более сбалансированное соотношение precision/recall.  
- Значение PR-AUC у GCN выше, что указывает на лучшую способность к ранжированию мошеннических транзакций.

Более сложная архитектура (GAT) не продемонстрировала прироста качества в рассматриваемой постановке.

### Вывод

После перехода к корректной методологической постановке установлено:
- GCN превосходит GAT по PR-AUC;  
- механизм attention не обеспечивает улучшения качества на данном графе;  
- GCN целесообразно использовать в качестве базовой архитектуры для дальнейшей оптимизации.

Данный этап фиксирует переход от оценки по accuracy к строгому анализу качества модели в условиях сильного дисбаланса классов.
