### 1. Постановка эксперимента  
  
Задача: выявление мошеннических адресов (fraud = 1) в блокчейн-графе Elliptic.  
  
Цель эксперимента: проверить, насколько SemiGNN способна отделять illicit-адреса от licit-адресов на ограниченном подграфе из 3000 узлов при сильном дисбалансе классов.  
  
### 2. Подготовка данных  
  
Для эксперимента использовались:  
  
- `features.npy` — признаки узлов;  
- `labels.npy` — метки классов;  
- `adj.npz` — матрица смежности.  
  
Предобработка:  
  
- удалены узлы с неизвестной меткой;  
- выделен подграф размером 3000 узлов;  
- граф симметризован;  
- добавлены self-loops;  
- выполнено разбиение на train / validation / test.  
  
### 3. Конфигурация модели  
  
Используемая архитектура:  
  
- SemiGNN из DGFraud-TF2;  
- один view графа;  
- признаки узлов подаются в модель через отдельную проекцию;  
- supervised-ветка обучается с умеренными class weights;  
- порог классификации подбирается по validation.  
  
### 4. Настройка обучения  
  
Ключевые параметры эксперимента:  
  
- `sample_size = 3000`  
- `alpha = 0.7`  
- `class_weight_vec = [1.0, 1.5]`  
- early stopping по validation F1;  
- подбор порога по validation для fraud-класса.  
  
### 5. Результаты  
  
Итоговые метрики на test set:  
  
- Accuracy: 0.7883  
- Precision (fraud): 0.2830  
- Recall (fraud): 0.7759  
- F1-score (fraud): 0.4147  
- ROC-AUC: 0.8428  
  
Confusion matrix:  
  
- TN = 428  
- FP = 114  
- FN = 13  
- TP = 45  
  
### 6. Интерпретация результатов  
  
Модель показала хорошую способность ранжировать подозрительные адреса: ROC-AUC выше 0.84 и высокий recall по fraud-классу.  
  
При этом precision остаётся умеренным, что означает наличие ложноположительных срабатываний. Для AML-задачи это допустимый компромисс, поскольку пропуск мошеннического адреса обычно хуже, чем дополнительная проверка подозрительного адреса.  
  
### 7. Аналитический вывод  
  
SemiGNN в текущей конфигурации хорошо подходит для задач AML, где важна высокая чувствительность к мошенническому поведению.  
  
На подграфе из 3000 узлов модель смогла:  
  
- уверенно отделять fraud-адреса от нормальных;  
- показать сильное ранжирование объектов;  
- сохранить баланс между recall и precision.  
  
### 8. Ограничения эксперимента  
  
- эксперимент выполнен на подграфе, а не на полном графе;  
- метрики зависят от порога классификации;  
- результаты не следует напрямую сравнивать с full-graph экспериментами без указания протокола.
