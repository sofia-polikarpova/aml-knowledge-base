### 1. Постановка эксперимента

Задача: выявление мошеннических транзакций (fraud detection) в графе блокчейн-транзакций.

Данные:
 • Узлы: 203 769
 • Рёбра: 234 355
 • Признаки: 165
 • Размеченные узлы: 46 564
 • Классы: 0 — легитимная транзакция, 1 — мошенничество

Обучение:
 • Полный граф (без подграфов)
 • Обучение только на размеченных узлах
 • Оценка на test_mask
 • Device: CUDA

Основные метрики:
 • PR-AUC
 • F1-score (для класса fraud)
 • Precision / Recall

### 2. Результаты моделей

**GCN**
- PR-AUC: 0.71
- F1 (fraud): 0.56

Характеристика:
 • Стабильный baseline
 • Хороший общий баланс
 • Умеренный recall
 
**GAT**
- PR-AUC: ~0.73
- F1 (fraud): ~0.58

Характеристика:
 • Лучший результат по PR-AUC
 • Лучше ранжирует положительный класс
 • Чуть выше precision по сравнению с GCN

**HAN**
- PR-AUC: 0.681
- F1 (fraud): 0.601

Classification report (fraud = 1):
 • Precision: 0.52
 • Recall: 0.70
 • F1: 0.60

Характеристика:
 • Лучший F1-score
 • Самый высокий recall
 • Более агрессивно выявляет мошеннические транзакции

### 3. Сравнительная таблица

| **Модель** | **PR-AUC** | F1 (fraud) |     Особенность     |
| :--------: | :--------: | :--------: | :-----------------: |
|    GCN     |   ~0.71    |   ~0.56    | Стабильный baseline |
|    GAT     |   ~0.73    |   ~0.58    | Лучшее ранжирование |
|    HAN     |   ~0.68    |   ~0.60    |    Лучший recall    |

### 4. Аналитический вывод
 1. По метрике PR-AUC лидирует GAT, что указывает на лучшую способность ранжировать положительный класс.
 2. По ключевой для задачи метрике F1-score (fraud) лучшей моделью является HAN.
 3. HAN демонстрирует наибольший recall (0.70), что критично для задачи выявления мошенничества, поскольку снижает вероятность пропуска fraud-транзакций.
 4. GCN остаётся устойчивым базовым решением, но уступает более сложным архитектурам.

### 5. Научный вывод для диплома

Обучение моделей на полном графе позволило раскрыть потенциал архитектуры HAN. При использовании всей структуры транзакционного графа модель продемонстрировала наилучший F1-score для класса мошенничества.

Таким образом:
 • GAT предпочтителен при приоритете качества ранжирования.
 • HAN предпочтителен при приоритете максимального выявления мошеннических операций.

Для задачи fraud detection, где критично минимизировать пропуск мошенничества, модель HAN является наиболее эффективной в текущей конфигурации.
