### Цель эксперимента

На данном этапе была реализована базовая GCN-модель для выявления мошеннических транзакций в графе Bitcoin (Elliptic dataset).

Задачи этапа:
- построить граф транзакций
- подготовить признаки и метки
- обучить двухслойную GCN
- компенсировать классовый дисбаланс
- получить baseline-результаты
- оценить качество выявления illicit-транзакций

### Датасет

Использованы файлы:
```

elliptic_txs_edgelist.csv

elliptic_txs_classes.csv
```

**Дисбаланс**
- Illicit ≈ 11%
- licit ≈ 89%

### Предобработка

1. Замена inf → nan
2. Замена nan → 0
3. Нормализация StandardScaler
4. Добавление class weights

```
weight_illicit = 1 / num_illicit
weight_licit   = 1 / num_licit
```

### Архитектура модели
```
GCN(
  (conv1): GCNConv(165, 64)
  (conv2): GCNConv(64, 2)
)
```

**Параметры:**
- lr = 0.001
- weight_decay = 5e-4
- 30 эпох

### Интерпретация

**Recall (Illicit) = 0.9067**

Модель находит ~90% мошеннических транзакций.

**Precision (Illicit) = 0.4456**

Среди найденных мошенников только 44% действительно мошенники.
Есть значительное количество false positives.

**Accuracy = 0.866**

Не является основной метрикой из-за дисбаланса.
Если предсказывать всё как licit → accuracy ≈ 0.89.

### Вывод

GCN демонстрирует:
- высокую чувствительность к illicit-паттернам
- способность использовать структуру графа
- эффективность в задачах AML

Однако:
- precision остаётся умеренным
- требуется улучшение discrimination способности

- показывает, что графовая структура содержит информативные сигналы
