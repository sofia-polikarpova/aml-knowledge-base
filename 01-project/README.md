# Диплом: AML-анализ блокчейн транзакций

Разработка программного средства для автоматического обнаружения подозрительных транзакций в блокчейн-сетях с использованием машинного обучения, в частности графовых нейронных сетей.

**Цель проекта:** исследовать и адаптировать современные графовые нейросетевые модели (GNN) для задачи выявления подозрительной активности (fraud / money laundering) в блокчейн-сетях, с фокусом на Ethereum и возможностью переноса на другие блокчейны.

Проект носит исследовательский характер и ориентирован на работу с реальными блокчейн-данными.

**Ключевые технологии:**
- Графовые нейронные сети (DGFraud-T2)
- Обработка блокчейн-транзакций
- AML
- Машинное обучение для финансовой безопасности

## Цели и задачи

### Основная цель
Создать программное средство для автоматического детектирования подозрительных транзакций в блокчейне с использованием ML-подходов.

Задача AML в блокчейне формулируется как задача анализа **графа транзакций**, где:
- узлы — адреса или агрегированные сущности (user, CEX, DEX, mixer и др.),
- рёбра — транзакции между ними.

Необходимо:
- выявлять подозрительные узлы;
- учитывать структуру графа, поведение адресов и временную динамику;
- работать в условиях ограниченной разметки данных.

### Конкретные цели
1. **Исследовательская** - Анализ современных ML-методов для AML-анализа
2. **Техническая** - Разработка архитектуры обработки блокчейн-данных
3. **Научная** - Адаптация графовых моделей для финансового мониторинга
4. **Практическая** - Создание работающего прототипа системы

## Выбранный подход

В качестве базового подхода используется **графовое машинное обучение**:

- Semi-supervised Graph Neural Networks;
- Graph Attention Networks (GAT, HAN);
- multi-view представление графа.

В качестве основной архитектурной базы рассматривается **SemiGNN** из фреймворка **DGFraud-TF2**, как наиболее релевантная для задачи fraud detection.

# Методология

### Научные подходы
1. **Сравнительный анализ** - оценка эффективности разных ML-методов
2. **Экспериментальная валидация** - тестирование на реальных данных
3. **Итеративная разработка** - постепенное улучшение системы

### Основные технологии
- **Языки программирования:** Python 3.8+
- **ML-фреймворки:** PyTorch, DGL, Scikit-learn
- **Блокчейн-анализ:** Web3.py, Blockchain APIs
- **Визуализация:** Matplotlib, Plotly, NetworkX
- **Документирование:** Obsidian, GitHub, Markdown

### Метрики оценки
- **Качество моделей:** Precision, Recall, F1-Score
- **Производительность:** время обработки, масштабируемость
- **Практичность:** удобство использования, соответствие требованиям

## Текущий прогресс

**1. Анализ предметной области**

- Изучены особенности AML-задач в блокчейн-сетях;
- Проанализированы отличия блокчейн-графов от классических финансовых графов;
- Выявлены ключевые сложности: гетерогенность, временная динамика, дисбаланс классов.

**2. Анализ и сравнение моделей**

Изучены архитектуры GNN, применяемые для fraud detection:

- GAT (Graph Attention Network);
- HAN (Heterogeneous Attention Network);
- EvolveGCN;
- SemiGNN

Проанализированы механизмы attention и способы вычисления "важности" узлов и рёбер;

Выполнен обзор алгоритмов, представленных в DGFraud-TF2, с анализом их применимости к блокчейн-AML.

**3. Анализ реализации SemiGNN**

- Изучен исходный код SemiGNN в репозитории DGFraud-TF2;
- Выявлены ограничения базовой реализации (отсутствие edge-features, временной динамики);
- Предложены пути адаптации модели под блокчейн-данные.

**4. Формирование требований к данным**

- Определены обязательные поля транзакций;
- Разделены исходные транзакционные данные и агрегированные признаки;
- Показана связь между набором признаков и attention-механизмом GNN.

**5. Универсальный набор признаков для блокчейнов**

- Сформирован базовый набор признаков, применимый к различным блокчейнам;
- Признаки структурированы на node-features, edge-features и temporal-features;
- Обоснована переносимость модели между сетями.

**6. Анализ Ethereum-специфики**

- Проанализирован открытый Ethereum-датасет для fraud detection;
- Изучены возможные признаки адресов в сети Ethereum;
- Выполнено поверхностное введение в стандарт ERC-20 и его влияние на признаки;
- Сформированы идеи для feature engineering.

**7. Формирование набора признаков для GNN на Ethereum**

- Сформирован Bitcoin-подобный базовый набор признаков;
- Добавлены Ethereum-специфичные расширения (контракты, ERC-20);
- Определён минимальный рабочий feature set для первых экспериментов.

### Текущее состояние проекта

На текущий момент:

- теоретическая и методологическая часть проекта проработана;
- выбран и обоснован основной модельный подход;
- сформированы требования к данным и признаки;
- проект готов к переходу в стадию практических экспериментов.

## План дальнейших работ

**Этап 1. Получение и подготовка данных**

- Получение доступа к базе данных Ethereum;

- Формирование графовой структуры;

- Подготовка обучающих и тестовых выборок.

**Этап 3. Эксперименты с моделью**

- Запуск базовой версии SemiGNN;
- Обучение модели на сформированном датасете;
- Анализ качества и устойчивости результатов.

**Этап 4. Улучшения и анализ**

- Добавление репутационных и семантических признаков;
- Анализ attention-весов;
- Оценка применимости модели в режиме близком к реальному времени.

**Ожидаемый результат**:

- Адаптированная GNN-модель для AML-анализа блокчейн-транзакций;
- Формализованный pipeline подготовки данных;
- Анализ влияния различных признаков на качество детекции;
- Выводы о применимости подхода для реальных AML-сценариев.

### Обновление статуса проекта (январь 2026)

**Что уже сделано**

1. Проанализированы существующие подходы к задаче AML и принято решение **не использовать классические модели AML (CatBoost-based)** ввиду их неприменимости к блокчейн-данным.
2. Выбрана и обоснована модель **DGFraudT2** как наиболее релевантная для анализа транзакционных графов в криптовалютах.
3. Изучены и законспектированы ключевые научные работы:

- Graph Attention Networks (GAT) и механизмы attention в графах;
- Transfer learning для AML (Kaggle EvolveGCN);
- Semi-supervised Graph Attentive Network for Financial Fraud Detection (SemiGNN) — как основная архитектура-кандидат;
- Подходы к Dual Attention (node-level + edge-level).

4. Проведён сравнительный анализ алгоритмов, представленных в DGFraudT2, с точки зрения решаемой задачи, применимости к блокчейн-графам и возможности работы в режиме near-real-time.

5. Сформировано понимание важности **различного «веса» узлов** (CEX / DEX / mixer / EOА) и необходимости учитывать типы узлов в attention-механизмах (HAN-подход).

**Работа с признаками и данными**

1. Сформирован **универсальный набор признаков**, применимый к любому блокчейну (node / edge / temporal / graph-level features).

2. Отдельно проанализированы особенности Ethereum:

- адреса EOА и smart contracts;
- взаимодействие с ERC-20 токенами;
- изучен публичный Ethereum fraud dataset (Kaggle) с целью извлечения идей по признакам, без прямого копирования.

3. Собран и структурирован **набор признаков для GNN на Ethereum**, с поэтапным усложнением от Bitcoin-подобной модели к Ethereum-специфике.

**Реализация и инструменты**

Изучена реализация **SemiGNN в DGFraudT2**, проанализированы возможные улучшения для блокчейн-задачи:

- расширение node/edge features;
- использование Dual Attention;
- адаптация под потоковую (on-the-fly) оценку адресов.

Подготовлена база знаний в Obsidian, связанная с GitHub-репозиторием, отражающая:

- изученные статьи;
- модели и алгоритмы;
- признаки и данные;
- архитектурные решения.

**План дальнейших шагов**

1. Получение доступа к реальным данным Ethereum (и далее Bitcoin).
2. Формирование выборок вида:
```

```

3. Подготовка датасета под SemiGNN / HAN-подобную архитектуру.
4. Проведение первых экспериментов и анализ качества модели.
