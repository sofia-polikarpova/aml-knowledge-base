**Общая информация о статье**

**Название:** Anti-Money Laundering in Bitcoin: Experimenting with Graph Convolutional Networks for Financial Forensics **Источник:** arXiv:1908.02591 (KDD Workshop) **Авторы:** Mark Weber et al.

Данная работа является одной из первых академических статей, в которых графовые нейронные сети применяются к задаче AML-анализа транзакций Bitcoin на реальных данных.

**Elliptic Data Set**

**Описание датасета**

Узлы графа — отдельные Bitcoin-транзакции

Рёбра — потоки средств между транзакциями

Размер: ~200 000 узлов, ~234 000 рёбер

Признаки: 166 числовых признаков для каждой транзакции

Метки классов: licit (легальные), illicit (нелегальные)

Датасет является частично размеченным и отражает реальные сценарии финансовых расследований.

Описание используемого датасета вынесено в [[Elliptic Data Set]].

**Временная структура данных**

Транзакции распределены по **49 временным шагам**, что позволяет рассматривать транзакционный граф как **динамический**.

Это особенно важно для задач AML, так как мошенническая активность часто проявляется не мгновенно, а в виде временных паттернов.

**Используемые модели**

В рамках исследования были рассмотрены следующие подходы:

1. Logistic Regression
2. Random Forest
3. Multilayer Perceptron (MLP)
4. Graph Convolutional Network (GCN)

GCN используется для учёта структурных зависимостей между транзакциями, которые не учитываются в классических ML-моделях.

**Основные результаты**

- Random Forest показал наилучшие значения F1-метрики
- GCN продемонстрировал конкурентоспособные результаты
- Графовая структура оказалась важным источником информации

Авторы отмечают, что GCN особенно полезны для захвата взаимосвязей между транзакциями, несмотря на более сложную настройку и обучение.

  
**Ограничения исследования**

- Ограниченное количество размеченных данных
- Сложность интерпретации результатов GCN
- Статическая архитектура GCN без явного учёта эволюции параметров во времени

Эти ограничения мотивируют использование более продвинутых архитектур, таких как EvolveGCN.

**Значимость для диплома**

Данная статья:

1. Подтверждает применимость GNN для AML-задач;
2. Служит академическим обоснованием выбора графовых моделей;
3. Демонстрирует необходимость учёта временной динамики;
4. Подчёркивает актуальность дальнейших исследований в направлении GAT и EvolveGCN.
